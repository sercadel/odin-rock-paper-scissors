# Rock Paper Scissors

## Descripción

Proyecto del curso Foundations de The Odin Project. Implementación del juego Piedra, Papel o Tijera jugable en la consola del navegador.

## Habilidades demostradas

- Lógica de programación con JavaScript
- Funciones y alcance (scope)
- Generación de números aleatorios
- Control de flujo (condicionales)
- Interacción con usuario mediante prompt() y console.log()
- Control de versiones con Git
